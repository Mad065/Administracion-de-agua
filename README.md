# Administración de agua

Simulador web de la distribución de agua entre la calle, una cisterna, un tinaco y una llave de salida.

## Funcionamiento

La interfaz modela los estados de cada elemento y muestra el estado resultante del sistema. La capacidad configurada en el código es de 8,000 para la cisterna y 1,000 para el tinaco.

## Uso

No requiere instalación. Abre `index.html` en un navegador web.
